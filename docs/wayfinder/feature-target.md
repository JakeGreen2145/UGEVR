# UGEVR feature target

The user selected the full UEVR capability target with staged delivery. This index contains **149 audit entries**, including overlapping facets across the three audits. It does not claim 149 independent features or universal game compatibility.

Each feature link opens its immutable audit row, with the inspected UEVR mechanism, commit-pinned primary-source references, limits and an observable acceptance criterion. The [machine-readable registry](feature-target.json) also records those criteria. Static source evidence and documented claims are distinguished in the linked rows; neither means runtime validation.

All Unity outcomes below are targets. Baseline status refers to the existing proof of concept, whose successful runs used simulated headset tracking in two title scenes. Physical-headset gameplay remains unverified.

The stage column proposes when capability work begins. Foundational subsets often start earlier than advanced parity, so a subsystem can span several stages. Stage gates and architecture remain human decisions on the [Wayfinder map](https://github.com/JakeGreen2145/UGEVR/issues/1). See [decomposition](decomposition.md) for S1-S5 definitions and [source provenance](source-provenance.md) for snapshots and the SDK distinction.

External denotes a companion integration, not a capability implemented by UEVR core. Documented hardware bindings are a target for supported input profiles, not proof that every listed device works.

## Overlap and exclusions

The inventory preserves facets rather than adding duplicate implementation obligations. R11/I64/P33 concern shared tracked poses; R12/I30/I31 concern origin and recentering; R18-R21/I32-I35 concern camera behavior; R22/I41 concern screen presentation; R32/P25-P28 concern configuration/console controls; R24/P11-P12 concern recovery; I55-I60/P43 concern authored tracked objects. Their decision tickets reconcile common contracts.

No working dolly-zoom feature is inferred from the declared, unconsumed CameraFOVDistanceMultiplier setting. No universal game-widget ray interaction, proportional trigger mapping, gameplay-aware weapon attachment, independent spectator camera, online profile catalog, or all-games compatibility is inferred from broader wording. Those require separate evidence and would be extensions where UEVR does not establish them.
