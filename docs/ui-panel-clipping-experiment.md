# Experimental root-panel clipping

`UI.PanelClipping=none` is the default. The experimental selection `canonical-ugui-default-root-v1` requires both `UI.CaptureOverlayCanvases=true` and `UI.OverlayAfterImageEffects=true`. Unknown selections refuse. This selection has not established a native crop effect or restored desktop rendering on a game. It targets off-panel strips, and makes no claim about the circle or arms observed in earlier UI trials.

The adapter admits only the two inspected public UGUI builds, identified by module IDs `77113f89-90f5-421e-9612-be5b86cac085` and `576a1661-0fc3-4a1a-9fd2-ae2d01246769`. It resolves exact public Image/Text types and public getter signatures at opt-in construction. It does not add a UnityEngine.UI assembly reference to the shipping net35 project. A missing, ambiguous, uninspected or incompatible loaded UGUI assembly refuses before clipping writes.

In both inspected assemblies, exact Text inherits Graphic's material/default-material getters and UpdateMaterial; no Text or MaskableGraphic override was found. The inherited getter returns an assigned material or the public default reference. The renderer still has to pass an independent slot readback. A Text using a separate assigned/font material refuses the entire selected root. Image's public material override can return a separate ETC1 split-alpha default, which also refuses. Eligibility of a game's actual HUD cannot be inferred from its Text/Image component labels. There is no new root-selection override; every selected active root must pass.

When the overlay scope's selected snapshot has zero roots, selected clipping is `not_applicable_no_selected_roots`, with `admitted=false` and `selectedRootCount=0`. It constructs no clipping adapter and makes no clipping-specific queries or setters. Ordinary game-eye rendering continues. This describes the selected snapshot for that pair, and does not claim coverage of UI that appears later during rendering. A later fresh nonempty snapshot must pass full admission. Explicit empty clipping scopes still refuse, and the adapter reports excess roots separately without relaxing the 64-root bound. The earlier combined empty/excess error alone cannot establish a physical launch's actual root count or cause.

Every renderer must have one active exact Image or Text, the selected root canvas, and exactly one material equal to the public `Graphic.defaultGraphicMaterial` reference. Its shader must equal that material's shader reference retained at admission. No guessed shader names, explicit Material creation, per-renderer material instantiation or `materialForRendering` getter is used. The latter can invoke material modifiers. Public UGUI default-material getters can initialize their shared default-material caches; the experiment does not promise untouched cache state. Separate custom materials/shaders, custom graphics, extra material/mesh/clipping modifiers, pop materials/instructions and supported nonzero clipping softness refuse. This adapter proves references and inspected public class behavior. It does not prove immutable contents of a shared default material or shader that the game may have modified before admission.

Before borrowing, the complete selected-root component inventory and ancestor chains must be inspectable. Missing component slots, any Mask/RectMask2D including disabled components, nested canvases, inactive descendants, pre-existing native clips, empty renderer sets, required getter errors and nonfinite required fields refuse. Limits are 64 selected roots, 128 ancestors per root, 65536 total inspected component/reference occurrences, 8192 renderers, 64 attached components per renderer and 8 material slots. Unity allocates complete component arrays before these inspection limits are checked. These limits do not bound Unity's native query allocation. No truncated prefix can admit a crop.

The scope records the actual root rectangle and four-world-corner conversion into that root's canvas-local coordinates. It also records each child's rectangle in the same coordinates. After the common panel's final placement, and after the game-eye render, it checks fresh identity, hierarchy, activity, component inventory, material references and panel placement before enabling a root-local crop immediately around the isolated UI-eye render. Root rectangles and placed poses must remain exact; changing child geometry is observed, and no child transform is written by the clipping helper.

Cleanup attempts `DisableRectClipping` once for each potentially written renderer, including an Enable call that threw. It requires the retained public identity/context before the write. Lost context preserves the current state and reports a conflict; a failed Disable is not retried blindly. Cleanup occurs before the existing overlay disposal and desktop layout rebuilds. Fresh post-UI, post-cleanup and final desktop observations compare supported fields. A changed cull/color/alpha value is preserved and reported; the clipping helper has no cull, color, alpha, softness, material, Animator, component or hierarchy setter.

The original observable clip flag must be false, and cleanup verifies false. Neither shipped API provides a getter for the active native clipping rectangle. A foreign callback that replaces the rectangle while keeping the flag true cannot be detected, and cleanup can disable that foreign replacement. Explicit activation accepts this limited flag cleanup; it does not promise foreign-rectangle preservation, continuous ownership, detection of changes that are later reverted, or complete native-state restoration. Meshes, textures, alpha textures, material contents and native batch state remain outside the public snapshot proof.

Capture/failure JSON adds `panelClipping` only when selected. It retains up to eight observations and the first 64 renderer details per observation, with explicit omitted counts and a 262144-character observation budget. Detailed rows contain renderer/root/graphic/child IDs, direct and converted panel rectangles, child rectangles, clip/cull/color/alpha, supported inherited alpha/softness, material/shader/pop identities and pop instructions. Firewatch2017 lacks public inherited-alpha and softness getters; those values remain null with `public_getter_unavailable`. The clipping selection performs these bounded observations each selected eye pair. `CaptureNativeUiState` is independent and is not forced on. When clipping is off, it creates no adapter and performs no clipping-specific queries or setters.

Controlled managed checks verify admission refusals, rotated/scaled coordinate conversion, inside/outside geometry data, setter/render failures, changed context, preservation of unrelated alpha changes, default-off behavior, query limits and cleanup ordering. These checks model public APIs and do not prove native shader output. A later owned physical trial needs a neutral same-state baseline and cropped pair, visible off-panel removal with retained inside-panel HUD/menu content, and original desktop rendering after cleanup. Clip flags and rectangle arithmetic alone cannot establish that result.

## Physical admission result

The `f92b2e3` distribution was tested in a fresh Firewatch launch with clipping explicitly selected and game-input adapters disabled. World rendering initially became active; the first retained frame report selected zero UI roots. A later nonempty selection refused with `panel_clip_inactive_descendant`, and submission stopped at 113 pairs. The failing component/root identity and its native failure time were not captured. No crop comparison or readable-menu evidence was obtained. This is a known failing selection, not evidence that inactive descendants can safely be ignored.

The first archived game log already contained the refusal. The operator initially inspected only its frame reports and attempted mouse interaction afterward; those actions should have stopped. Their delivery was unverified and contributes no menu or gameplay credit. The raw trial and its correction remain preserved. Owned game, deployment, configuration, stream and lease cleanup completed. Complete in-process native restoration remains unproved. See the [issue's physical result and correction](https://github.com/JakeGreen2145/UGEVR/issues/32#issuecomment-6176291131).
