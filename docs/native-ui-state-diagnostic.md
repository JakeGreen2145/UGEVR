# Native UI state observations

`Diagnostics.CaptureNativeUiState=false` enables a diagnostic for requested image captures. It requires `CaptureImages=true`, overlay capture, and a `capture-request` already present before the eye pair begins. Disabled and unrequested pairs perform no native UI sampling. A request arriving during a pair can still collect the existing images, but that pair reports `nativeUiState=null`; request another capture for this diagnostic.

The adapter admits CanvasRenderer references from the selected overlay roots' existing hierarchy inventories. It performs no extra scene or canvas inventory query. Admission permits at most 1024 renderer references and 8192 encountered occurrences that can perform identity queries. Later occurrences are counted as drops, including possible duplicates. Names are bounded to 64 UTF-16 units. The renderer set is fixed before borrowing; newly created renderers are not admitted during callbacks.

Existing capture and restoration-failure JSON include `overlayCapture.nativeUiState` for admitted pairs. Each renderer records public `cull`, `hasRectClipping` and local `GetAlpha()` values before borrowing, after each returned or failed game-eye render, after each separate UI-eye render, and after the outer camera/UI restoration. Unused UI passes remain explicitly uncaptured. Sampling after a render does not prove that those were the values during every GPU draw.

Inherited alpha is a separate optional observation. Shipped-artifact inspection found public `GetInheritedAlpha()` in Outer Wilds' Unity 2019.4.39f1 UIModule, but not Firewatch's Unity 2017.4.40f1 UIModule. Reflection admits only the exact CanvasRenderer-declared public instance method with no arguments, a float return, no generic parameters and no virtual dispatch. Missing or unsupported shapes report `inheritedAlphaAvailable=false`; local alpha is never labeled inherited alpha. Both versions expose the common culling/clipping/local-alpha getters, and both game-reference builds compile this diagnostic.

Each phase also records the current `RenderTexture.active` identity, `Camera.current` identity and target, and the selected game camera's target. These are engine property observations, not a complete Direct3D render-state snapshot. Nulls and getter errors remain distinct through per-phase error counts.

The summary reports admitted/dropped/duplicate occurrences, admission errors, getter attempts, query errors, nonfinite values, destroyed samples and captured phases. Nonfinite numeric values serialize as null with an explicit counter. Renderer IDs and context values are private, current-run evidence. Serialization performs no new engine queries.

The diagnostic never assigns cull, clipping or alpha values. It requests no extra rendering, layout rebuild, material query or preferred-size calculation. It neither relaxes existing guards nor asserts that native UI state was restored. Native batching, clip rectangles, materials, shader globals and queued GPU commands remain outside its observations. Diagnostic getter overhead can change frame timing, so these captures do not qualify performance.

Unity documents [cull as whether emitted geometry is ignored](https://docs.unity3d.com/2019.4/Documentation/ScriptReference/CanvasRenderer-cull.html). Its [CanvasRenderer API](https://docs.unity3d.com/2019.4/Documentation/ScriptReference/CanvasRenderer.html) lists the clipping flag and alpha methods. The [uGUI clipping implementation](https://raw.githubusercontent.com/Unity-Technologies/uGUI/2017.4/UnityEngine.UI/UI/Core/MaskableGraphic.cs) changes culling state and invokes culling callbacks. These sources justify observing the fields; unchanged observations alone cannot establish that the desktop UI was drawn correctly.
